# Speedrun Bingo

Bingo card generator for speedruns — lightweight web interface with customizable settings.

## Features

- Random Bingo card generation
- Customizable settings
- Minimalist interface built with HTML/CSS/JavaScript
- Easy to modify and extend for custom rules

## Usage

1. Clone and open `index.html` in your browser (or use he link to github pages).
2. Adjust options if you want to customize behavior.
3. Generate your seed and send it to your friends.
