About Generic Bingo

This is a bingo board for a non-specific multi-game race.

Each square can be completed in any game where such a goal is possible.

Any restrictions on the games allowed should be agreed upon before the race starts.



Rules:

  • Speedrun - The game you chosse must be played on a new save, no older saves.
    • Exept: "Online/multiplayer games, you have to play as if you had a new account."
  • 5 Games - Must use a different game for each goal.
  • Creative - Creative mode is not allowed in any games.
  • Mods - You are not allowed to use any kind of mod.
  • Cutscene - All goals must be complete in game not No Cutscene.
  • Platform - Games must be released on the specified platforms. (Ex. "Console/Steam", "N64", etc.) No Emulators!
  • Penality - Optional For a more stimulating game use the prenitences.
    • Every tome you win you get a point.
    • You can spend your points to inflict a penalty on another player.
    • If the player you used the penalty on wins the game, he gets his point plus the cost of your penalty.
